An adaptive, responsive, and lightweight Sports Schedule, Live Scores, Odds & TV Broadcast Guide widget for websites, web apps, and WordPress. 

Displays real-time match schedules across 27+ international sports disciplines, localized kickoff times converted to each visitor's timezone, verified official television channels, live in-play score tracking, and community prediction trends.

## 🚀 Key Features

* **27+ Supported Sports**: Soccer, Basketball (NBA, Euroleague), Ice Hockey (NHL), Tennis (ATP, WTA, Grand Slams), American Football (NFL), Baseball (MLB), Volleyball, Handball, Esports, and more.
* **Automatic Local Time Conversion**: Kick-off times automatically adjust to the visitor's local system timezone.
* **Official TV Broadcasters**: Identifies legal rights holders and broadcast channels per country.
* **Live In-Play Scores**: Automatically updates live scores, periods, and match completion statuses without page reloads.
* **Prediction Trends & Decimal Odds**: Displays market-implied probabilities, outcome percentages, or clean decimal odds.
* **Isolated Shadow DOM**: Completely immune to parent CSS conflicts and theme overrides.
* **WordPress Plugin Included**: Official shortcode `[live2sport_widget]` with configurable admin settings.
* **Zero External Dependencies**: Standalone lightweight JavaScript vanilla bundle.

## 💻 Installation & Usage

### 1. WordPress Plugin Setup

The official plugin is available on the WordPress Plugin Directory:  
👉 **[Download Live2Sport on WordPress.org](https://wordpress.org/plugins/live2sport-tv-guide-live-scores-predictions/)**

1. In your WordPress admin panel, go to **Plugins > Add New** and search for `Live2Sport` (or upload the plugin ZIP).
2. Activate **Live2Sport – TV Guide, Live Scores & Predictions**.
3. Insert the shortcode into any post, page, or widget area:

```text
[live2sport_widget sport="soccer"]
```

#### Shortcode Options

| Parameter | Options | Default | Description |
| :--- | :--- | :--- | :--- |
| `sport` | `soccer`, `basketball`, `hockey`, `tennis`, etc. | `soccer` | Primary sport tab to display on load. |
| `odds_display` | `odds`, `percent` | `odds` | Display format: decimal odds or market probabilities. |
| `match_links` | `yes`, `no` | `no` | Enable clickable links to full match guides on TVEvents. |
| `credits` | `yes`, `no` | `no` | Displays optional footer attribution. |
| `date` | `YYYY-MM-DD` | Current Date | Displays fixtures for a specific calendar date. |

*Example with custom options:*
```text
[live2sport_widget sport="basketball" odds_display="percent" match_links="yes"]
```

---

### 2. Standalone HTML / Embed Widget (Any Website)

To embed the widget on any HTML website, Webflow, Wix, or Shopify:

```html
<!-- Container element -->
<div class="sports-widget-embed" data-sport="soccer" data-match-links="0"></div>

<!-- Load widget engine -->
<script src="https://nazarini18.github.io/live2sport-sports-widget/sports-widget.js" async></script>
```

---

### 3. npm and jsDelivr CDN

Install via npm:

```bash
npm install live2sport-sports-widget
```

Or load directly via CDN (jsDelivr / unpkg):

```html
<div class="sports-widget-embed" data-sport="soccer"></div>
<script src="https://cdn.jsdelivr.net/npm/live2sport-sports-widget@1.0.0/sports-widget.js" async></script>
```
